# Pinned to 1.91.5 (up from 1.86.2): the floor carries the reasoning-stream fix. In
# 1.86.2 the Anthropic streaming adapter's content-block classifier
# (_translate_streaming_openai_chunk_to_anthropic_content_block in
# litellm/llms/anthropic/experimental_pass_through/adapters/transformation.py)
# returns "text" for a delta that carries only `reasoning_content`, the field
# DeepSeek and Moonshot send reasoning in (Anthropic- and Bedrock-shaped providers
# send `thinking_blocks` instead). So streaming_iterator.py opens content block 0
# as {"type":"text"} and then emits the model's reasoning into it as
# thinking_delta events, a shape Claude Code's Anthropic client rejects ("Stream
# event unreadable") before falling back to a non-streamed resend of the same
# turn. The provider bills both requests; LiteLLM logs only the resend, because it
# logs a stream only once it completes, so every such turn is billed twice but
# recorded once. 1.91.0 is the first release whose classifier adds `elif
# isinstance(choice, StreamingChoices) and getattr(choice.delta,
# "reasoning_content", None): return "thinking", ...`; 1.91.5 is the last 1.91
# patch release. Confirmed by reading both: the installed 1.86.2 venv, and the
# 1.91.5 wheel downloaded for this change (2026-10-19).
litellm[proxy]==1.91.5
